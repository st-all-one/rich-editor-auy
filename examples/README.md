# Examples

- `ts/main.ts`: quick start in 8 lines with no CSS import.
- `php/roundtrip.php`: byte-preserving PHP transport.
- `host/index.html`: consumer-owned styles; the library adds no `class` or `style`.
- `demo/`: live Rust + WASM + TypeScript + PHP editor with persistence, validation, import,
  tables, media, `raw_code`, IME, categories of marks, and a11y/DocView panels.

Run the TypeScript example from the repository root:

```sh
deno run --allow-read examples/ts/main.ts
```
